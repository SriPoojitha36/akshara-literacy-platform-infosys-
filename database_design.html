TASK 2 · DATABASE DESIGN

Intelligent literacy data model

All tables below are implemented in SQLite by the Flask backend. Primary keys are marked PK; foreign keys are marked FK.

Learner

  • PK id
  • name, age, email
  • password_hash
  • language, proficiency, goal
  • assessment, streak, XP

Language

  • PK id
  • name
  • code

Learner Language

  • FK learner_id
  • FK language_id
  • is_preferred

Course

  • PK id
  • FK language_id
  • title, description
  • proficiency_level

Topic

  • PK id
  • FK course_id
  • title, sequence_no

Lesson

  • PK id
  • FK topic_id
  • title, content
  • estimated_minutes

Assessment

  • PK id
  • FK course_id
  • title, assessment_type

Question

  • PK id
  • FK assessment_id
  • question_text
  • question_type, sequence_no

Answer

  • PK id
  • FK question_id
  • answer_text
  • is_correct

Assessment Result

  • PK id
  • FK learner_id, assessment_id
  • score
  • recommended_level

Learning Progress

  • PK id
  • FK learner_id, lesson_id
  • completion_percent
  • last_accessed_at

Recommendation

  • PK id
  • FK learner_id
  • recommendation_type
  • content, is_seen

Voice Assessment

  • PK id
  • FK learner_id
  • target_text, spoken_text
  • match_score

Learner Skill Score

  • PK learner_id, skill
  • mastery_score
  • attempts, updated_at

Learning Event

  • PK id
  • FK learner_id
  • event_type, skill, score
  • duration_seconds, created_at

Personalized Lesson

  • PK id
  • FK learner_id
  • skill, title, payload
  • status, completed_at

Learner Achievement

  • PK id
  • FK learner_id
  • badge_key, badge_name
  • unlocked_at

Social Account

  • PK id
  • FK learner_id
  • provider
  • provider_user_id

Password Reset

  • PK id
  • email, token
  • expires_at, created_at
Language → Course → Topic → Lesson
Course → Assessment → Question → Answer
Learner → Assessment Result / Learning Progress / Voice Assessment / Recommendation
Learner → Skill Score / Learning Event / Personalized Lesson / Achievement / Social Account
